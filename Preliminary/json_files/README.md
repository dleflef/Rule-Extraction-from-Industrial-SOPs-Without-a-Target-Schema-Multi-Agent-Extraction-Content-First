# Source and attribution

`svo.json` and `wiki.json` are taken unchanged from the NODES 2021 workshop
*Creating a Knowledge Graph with Neo4j: A Simple Machine Learning Approach* by
C. J. Sullivan, published at <https://github.com/cj2001/nodes2021_kg_workshop>
(files `json_files/svo.json` and `json_files/wiki.json`). The upstream repository
states no licence, so they are kept here for reference only.

They are used by the workshop notebooks in `../notebooks/` and form no part of the
pipeline reported in this repository. See `../SOURCES.md`.
